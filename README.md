EmotiDo is a web app that tracks how you feel about your work, not just what you've finished. Its motto is "Manage Your Tasks. Mind Your Mood."

The design was inspired by the Powerpuff Girls. It features bold, cheerful colors, playful hearts and sparkles, and a feel-good energy that makes a to-do list less of a chore. I wanted it to feel fun and a little heroic, as if every finished task were a small win for the day.

Each task gets a category (Work, Personal, School, or Other), a deadline, a status, and a mood tag: Neutral, Irritated, Motivated, Energetic, Blissful, Confused, or Enraged. Over time, users can see which tasks energize them and which drain them.

Key features:

- Create tasks with a category, deadline, status, and mood
- Filter by status (including Overdue tasks) and by category
- See everything in one table with quick actions for each task
- Use it on desktop or phone
